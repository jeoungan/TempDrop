# Changelog

All notable changes to TempDrop are documented here.

## [1.0.0] - 2026-07-22

### Added

- Native Windows desktop interface with drag-and-drop file import.
- Explicit first-run permanent-deletion consent.
- Per-file expiry dates and configurable 1–365 day default retention.
- Daily per-user Windows scheduled cleanup.
- Managed-folder containment checks and protected-folder blocking.
- Partial-download and NTFS reparse-point protection.
- Local JSON-lines deletion log with no network or telemetry.
- Per-user installer, portable ZIP, SHA-256 checksums, and automated GitHub Releases.
- Optional Authenticode signing in the release workflow.
